# Open_Lantu 用户认证模块核心代码

> 生成时间：2026-06-02 14:14（最后更新：2026-06-24）

## 功能概述

登录成功后，页面标题右侧的"登录/注册"按钮消失，替换为用户的头像和昵称，点击可弹出下拉菜单（含个人中心、每日签到、修改资料、修改密码、管理后台、退出登录）。

## 核心架构

```
用户登录/注册
    │
    ▼
auth.login(data)  ──── 写入 Pinia 响应式状态 ──── 自动驱动标题 UI 切换
    │
    └── 同时持久化到 sessionStorage（刷新后恢复登录态，关闭标签页即退出）
```

## 文件清单

| 文件 | 作用 |
|------|------|
| `stores/auth.ts` | **Pinia Store** — 认证状态管理（login/logout/isLoggedIn + 用户信息字段） |
| `api/index.ts` | **API 层** — 登录/注册接口定义 + UserInfo 类型（含 role、avatar 等） |
| `layouts/AppLayout.vue` | **标题组件** — 条件渲染登录按钮 / 用户信息 + 下拉菜单 |
| `views/LoginPage.vue` | **登录页** — 调用 auth.login() |
| `views/RegisterPage.vue` | **注册页** — 调用 auth.login() |

# 01 — Auth Store (`stores/auth.ts`)

Pinia 认证状态管理，是整个用户登录态的核心。

## 职责

- 应用启动时从 `sessionStorage` 恢复已保存的用户会话（**非 localStorage**，关标签页自动退出）
- 提供响应式的 `isLoggedIn`、`nickname`、`roleName` 等属性驱动 UI
- `login(userData)` — 写入状态 + 持久化到 `sessionStorage`
- `updateUser(data)` — 更新部分用户信息（如修改资料后同步到 store）
- `logout()` — 清除状态 + 清除 `sessionStorage`

## 完整代码

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { UserInfo } from '../api'

interface UserWithToken extends UserInfo {
  token: string
}

export const useAuthStore = defineStore('auth', () => {
  // 从 sessionStorage 恢复登录状态（关闭标签页即退出）
  const raw = sessionStorage.getItem('user')
  const saved: UserWithToken | null = raw ? JSON.parse(raw) : null

  const user = ref<UserWithToken | null>(saved)

  const isLoggedIn = computed(() => user.value !== null)

  // 用户信息计算属性
  const nickname = computed(() => user.value?.nickname ?? '')
  const name = computed(() => user.value?.name ?? '')
  const phone = computed(() => user.value?.phone ?? '')
  const email = computed(() => user.value?.email ?? '')
  const birthday = computed(() => user.value?.birthday ?? '')
  const avatarUrl = computed(() => user.value?.avatarUrl ?? '')
  const roleName = computed(() => user.value?.roleName ?? '普通用户')
  const roleId = computed(() => user.value?.roleId ?? 4)

  function login(userData: UserWithToken) {
    user.value = userData
    sessionStorage.setItem('user', JSON.stringify(userData))
    sessionStorage.setItem('token', userData.token)
  }

  function updateUser(data: Partial<UserWithToken>) {
    if (user.value) {
      user.value = { ...user.value, ...data }
      sessionStorage.setItem('user', JSON.stringify(user.value))
    }
  }

  function logout() {
    user.value = null
    sessionStorage.removeItem('user')
    sessionStorage.removeItem('token')
  }

  return {
    user,
    isLoggedIn,
    nickname,
    name,
    phone,
    email,
    birthday,
    avatarUrl,
    roleName,
    roleId,
    login,
    logout,
    updateUser,
  }
})
```

## 关键设计

1. **刷新持久化** — 构造函数中通过 `sessionStorage.getItem('user')` 恢复状态，页面刷新后登录态不丢失；关标签页自动清除（比 localStorage 更安全）
2. **统一入口** — 所有登录/注册都通过 `auth.login()`，确保状态和存储一致
3. **updateUser** — 修改资料后调用 `auth.updateUser()` 保持 store 与后端数据同步
4. **角色控制** — `roleId` 和 `roleName` 用于前端条件渲染管理后台入口
5. **退出清理** — `auth.logout()` 同时清除 Pinia 状态和 `sessionStorage`

# 02 — API 层 (`api/index.ts`)

定义后端接口调用和类型声明。

## 核心类型

```typescript
export interface UserInfo {
  id: number
  account: string
  nickname: string
  name?: string
  phone?: string
  email?: string
  birthday?: string
  avatarUrl?: string
  roleId?: number
  roleName?: string
}

export interface ApiResponse<T> {
  code: number
  message: string
  data: T
}
```

## 登录 / 注册接口

```typescript
/** 登录 */
export function loginApi(data: LoginRequest) {
  return api.post<ApiResponse<UserInfo & { token: string }>>('/auth/login', data)
}

/** 注册 */
export function registerApi(data: RegisterRequest) {
  return api.post<ApiResponse<UserInfo & { token: string }>>('/auth/register', data)
}
```

## 数据流

```
后端响应 (JSON)
  └─> ApiResponse<UserInfo & { token }>
        ├─ .data.id        → 用户 ID
        ├─ .data.account   → 账号
        ├─ .data.nickname  → 昵称（标题栏显示）
        ├─ .data.avatarUrl → 头像 URL
        ├─ .data.roleId    → 角色 ID（控制后台权限）
        ├─ .data.roleName  → 角色名称
        └─ .data.token     → JWT（sessionStorage 持久化）
```

# 03 — 标题布局 (`layouts/AppLayout.vue`)

核心的 **条件渲染逻辑** — 根据 `auth.isLoggedIn` 切换显示登录按钮或用户信息。

## 渲染逻辑

| 条件 | 桌面端显示 | 移动端显示 |
|------|-----------|-----------|
| `!auth.isLoggedIn` | 登录 \| 注册 按钮 | 登录 / 注册 链接 |
| `auth.isLoggedIn` | 头像（支持真实图片） + 昵称 + 下拉菜单 | 头像 + 昵称 + 操作按钮 |

## 下拉菜单内容

| 菜单项 | 条件 | 说明 |
|--------|------|------|
| 个人中心 | 始终 | 跳转 `/profile` |
| 每日签到 | 始终 | 跳转 `/checkin` |
| 修改资料 | 始终 | 跳转 `/profile/edit` |
| 修改密码 | 始终 | 跳转 `/change-pwd` |
| 管理后台 | `roleId === 1` | 仅管理员可见 |
| 退出登录 | 始终 | 清除登录态，跳转首页 |

# 04 — 登录页 (`views/LoginPage.vue`)

## 核心改动

登录成功后调用 `auth.login()` 替代直接操作 `sessionStorage`。

## Script 关键部分

```typescript
import { useAuthStore } from '../stores/auth'

const auth = useAuthStore()

async function handleLogin() {
  // ... 表单校验 ...
  loading.value = true
  try {
    const res = await loginApi({
      account: form.value.account,
      password: form.value.password,
    })
    if (res.data.code === 200) {
      message.success('登录成功')
      auth.login(res.data.data)    // ← 关键：通过 store 保存用户信息
      router.push('/')
    }
  } catch (err: any) {
    const msg = err?.response?.data?.message || '登录失败，请检查网络'
    message.error(msg)
  } finally {
    loading.value = false
  }
}
```

## 数据流

```
loginApi()  →  后端验证  →  返回 { id, account, nickname, token, avatarUrl, roleId, ... }
                              │
                              ▼
                       auth.login(data)
                              │
                    ┌─────────┴─────────┐
                    ▼                    ▼
              Pinia state          sessionStorage
          (驱动标题 UI 切换)     (刷新后恢复登录)
```

# 05 — 注册页 (`views/RegisterPage.vue`)

## 核心改动

注册成功后同样调用 `auth.login()`，与登录页共享同一套状态管理。

## Script 关键部分

```typescript
import { useAuthStore } from '../stores/auth'

const auth = useAuthStore()

async function handleRegister() {
  // ... 表单校验 ...
  loading.value = true
  try {
    const res = await registerApi({ /* ... */ })
    if (res.data.code === 200) {
      auth.login(res.data.data)    // ← 注册即登录，直接写入 store

      // 如有头像，上传
      if (avatarFile.value) {
        await uploadAvatarApi(avatarFile.value!)
      }

      message.success('注册成功')
      router.push('/birthday')
    }
  } catch (err: any) {
    // ...错误处理...
  } finally {
    loading.value = false
  }
}
```

## 注意

- 注册成功即视为已登录，无需用户再次输入密码
- 调用 `auth.login()` 后，标题会自动更新显示头像和昵称
- 注册响应包含 `token`，与登录一样自动持久化到 `sessionStorage`
