SVG 线条描边动画测试

四种玩法预览：入场描边 / 循环 Loader / 滚动描边 / 进度条 —— 原理均为 stroke-dasharray + stroke-dashoffset

① 加载入场描边 页面加载自动播放

页面打开时图形自动"一笔画"出。getTotalLength() 获取精确线长 → dashoffset 从线长动画到 0。

②a 循环 Loader — 圆环 CSS 动画

纯 CSS：stroke-dasharray 切出可见段，旋转 transform 让段"追赶"自己，形成转圈。

②b 循环 Loader — 沿路径行进 CSS 动画

小线段沿任意路径匀速前进：stroke-dashoffset 负值动画，一段"光点"沿轨迹循环。

③ 滚动触发描边 JS + 滚动进度

波浪线根据元素进入视口的比例逐段描边：滚到哪，画到哪。下方色块区域即滚动触发区间，请持续滚动页面观察。

▼ 继续向下滚动，让上方的波浪线"画"出来 ▼

④ 加载进度条 JS 模拟加载

路径描边长度 = 加载百分比。点击按钮模拟加载，进度每步推进，dashoffset 同步缩短。
