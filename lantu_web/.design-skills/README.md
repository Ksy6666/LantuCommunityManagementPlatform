# Designer Skills Collection

UI 设计 AI Agent 技能集，来源：https://github.com/Owl-Listener/designer-skills

## UI Design (14 skills)
- color-system — 色彩系统构建（色板生成、语义映射、无障碍合规）
- typography-scale — 字体比例（尺寸/字重/行高关系）
- layout-grid — 响应式网格系统（列/间距/边距/断点）
- spacing-system — 间距系统（4px/8px 基准单位）
- visual-hierarchy — 视觉层级（大小/字重/颜色/间距/位置）
- responsive-design — 响应式设计（布局适配/输入方式）
- von-restorff-effect — 孤立效应（关键元素视觉差异化）
- 以及 aesthetic-usability, dark-mode, data-visualization 等

## Visual Critique (4 skills)
- critique-visual-hierarchy — 视觉层级审查
- critique-brand-consistency — 品牌一致性审查
- critique-composition — 构图审查（平衡/留白/节奏/格式塔）
- critique-typography — 排版审查（比例/可读性/一致性/Token合规）
