# Color System
构建系统化、易访问的色彩体系。

## 色彩系统层次
### 1. 品牌色板
主色、辅色、强调色的完整色调比例（50-950 或等效）。

### 2. 中性色板
用于文本、背景、边框和表面的灰色阶。

### 3. 语义色
- Success（绿）、Warning（琥珀）、Error（红）、Info（蓝）
- 各有背景色、前景色、边框和图标变体

### 4. 扩展色板
数据可视化色、插画色、渐变定义。

## 无障碍要求
- 文本/背景：最小 4.5:1（AA）或 7:1（AAA）
- 大文本：最小 3:1
- UI 组件：最小 3:1 对比相邻色
- 不要仅依赖颜色传递信息

## 最佳实践
- 生成完整色调比例，而非单一色板
- 测试每对前景/背景组合的对比度
- 提供每种颜色的使用指南
- 考虑色盲设计（用模拟工具测试）
- 从一开始就包含暗色模式映射
