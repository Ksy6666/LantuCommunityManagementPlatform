# Spacing System
创建一致的间距系统。

## 基准单位
选择基准单位（通常 4px 或 8px）构建比例：
- 2xs：2px
- xs：4px
- sm：8px
- md：16px
- lg：24px
- xl：32px
- 2xl：48px
- 3xl：64px

## 间距类型
- **Inset**：容器内边距
- **Stack**：堆叠元素间的垂直间距
- **Inline**：行内元素间的水平间距
- **Grid gap**：网格/弹性元素间距

## 应用规则
- 相关项：小间距（sm/md）
- 不同区块：大间距（lg/xl）
- 页面边距：每个断点一致
- 组件内部：按组件定义

## 密度模式
- Compact：减少一级间距（数据密集视图）
- Comfortable：默认间距
- Spacious：增加一级间距（阅读聚焦）

## 最佳实践
- 始终使用比例尺——绝不用随意值
- 组件内间距一致
- 不相关组之间用更大间距
- 记录间距意图而非仅数值
- 在不同视口尺寸下测试间距
