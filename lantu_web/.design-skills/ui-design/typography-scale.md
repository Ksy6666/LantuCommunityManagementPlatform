# Typography Scale
创建模块化的字体比例系统。

## 比例构成
### 尺寸比例（基于比率，如 1.25 / 1.333）
- Caption：12px
- Body small：14px
- Body：16px（基准）
- Subheading：20px
- Heading 3：24px
- Heading 2：32px
- Heading 1：40px
- Display：48-64px

### 字重
Regular（400）、Medium（500）、Semibold（600）、Bold（700）

### 行高
- Tight：1.2（标题）
- Normal：1.5（正文）
- Relaxed：1.75（长文阅读）

### 字间距
- Tight：-0.02em（大标题）
- Normal：0（正文）
- Wide：0.05em（大写标签、说明文字）

## 字体搭配
- Primary：UI 和正文
- Secondary：标题或编辑用（可选）
- Mono：代码、数据、技术内容

## 响应式排版
- 移动端缩小标题尺寸
- 保持正文字号（16px 最低可读性）
- 调整行长（45-75 个字符最佳）

## 最佳实践
- 使用数学比例保持和谐
- 常规使用限制在 4-5 个尺寸
- 确保正文字号最小 16px
- 用真实内容测试，而非填充文本
- 为每种样式记录使用规则
