# Visual Hierarchy
建立清晰的视觉层级。

## 层级工具
### 大小
较大元素先吸引注意。差值至少 1.5x 以明确区分。

### 字重
粗体、粗笔画和填充图标比细体视觉权重更高。

### 颜色与对比
高对比度吸引注意力。策略性地为 CTA、状态和强调使用颜色。

### 间距
元素周围空白越多，感知重要性越高。

### 位置
左上角（LTR 布局）最先被看到。F 模式和 Z 模式扫描路径。

### 密度
孤立元素突出。分组元素作为整体被扫描。

## 层级级别
1. **Primary**：页面标题、主 CTA — 最先看到
2. **Secondary**：章节标题、关键内容 — 接下来扫描
3. **Tertiary**：支撑文本、元数据 — 按需阅读
4. **Quaternary**：小字、时间戳 — 可用但不突出

## 常用模式
- Hero 区：大标题 + 图片 + 单个 CTA
- 卡片布局：图片 > 标题 > 描述 > 操作
- 表单：标签 > 输入框 > 帮助文字 > 错误提示
- 导航：当前状态 > 可用 > 禁用

## 最佳实践
- 眯眼测试：模糊眼睛——层级仍应清晰
- 每个视图一个主要操作
- 不要争夺注意力——选择最重要的
- 用层级通过页面讲述故事
- 用真实用户做真实任务测试
