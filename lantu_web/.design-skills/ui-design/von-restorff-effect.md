# Von Restorff Effect（孤立效应）
确保最重要的元素在视觉上与其周围环境显著不同。

## 原理
与周围环境不同的项目更容易被**注意和记忆**。视觉同质性是基线，偏差吸引眼球。

- 一排幽灵按钮中的一个实心填充按钮捕获注意力
- 表格中高亮的行读起来像最重要的项目
- 价格、CTA 或警告在低对比度的周围环境中突出

## 关键区分
效果取决于**与上下文的对比**。如果一切都差异化，则没有差异。该原理仅在以下情况下有效：
- 一个（或极少）项目偏离
- 周围项目彼此视觉一致
- 偏差是有意义的，而非装饰性的

## 应用
| 上下文 | 如何应用 |
|---|---|
| 行动号召 | 一个填充/主按钮；其余为幽灵或文字按钮 |
| 定价 | 高亮推荐方案；降低其他方案的视觉权重 |
| 导航 | 激活状态明显不同于非激活状态 |
| 数据表 | 用高亮行或粗体标识关键记录 |
| 通知 | 徽章或强调色仅用于可操作项 |
| 引导 | 一次一步，视觉上隔离于后续步骤 |

## 避免
- 对多个竞争元素应用该效果
- 装饰性使用——随机的色彩会让用户忽略它们
- 仅依赖颜色——配合形状、大小或重量以确保无障碍

## 最佳实践
- 提前决定每个屏幕/部分中最重要的一元素
- 审查"孤立膨胀"——每个新功能请求高亮处理都会降低系统效果
- 确保差异化元素在所有状态下都可区分：悬停、焦点、禁用
- 用色盲模拟测试；差异化应在灰度下仍然可见
