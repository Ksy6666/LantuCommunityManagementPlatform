# Critique Composition
审查屏幕的构图——平衡、留白、节奏和格式塔原理。

## 审查维度

### 平衡（Balance）
视觉重量在布局中的分布。
- 构图是对称还是不对称平衡？选择是否有意？
- 重元素（深色填充、大图片、密集文本块）是否被轻元素抵消？
- 布局感觉稳定还是倾斜——头重脚轻、左倾？
- 是否有清晰的视觉重心？

### 留白（Whitespace）
负空间作为主动设计元素的使用。
- 主要部分之间是否有足够的宏观留白？
- 微观留白（标签、图标和相邻元素之间）是否一致？
- 留白是引导注意力，还是将布局分割成不连贯的区域？
- 是否有区域过度压缩或填充不一致？

### 节奏（Rhythm）
整个屏幕的重复、模式和视觉韵律。
- 间距间隔是否一致且源自间距比例？
- 重复元素是否保持统一尺寸和间距？
- 是否有变化而不混乱——重复与差异的平衡？

### 格式塔原理（Gestalt Principles）
布局如何利用感知分组。
- **邻近性**：相关元素是否靠近？无关元素是否明显分离？
- **相似性**：功能相同的元素是否有相同的视觉处理？
- **图/底**：前景内容是否与背景明显区分？
- **连续性**：对齐和流线是否平滑引导视线穿过构图？

## 常见失败模式
- 等权两栏布局，没有明确的主次之分
- 内边距不一致——有的 16px，有的 20px 或 24px，没有系统
- 孤立的元素漂浮着，远离它们的相关组
- 过度拥挤的区域与空区域相邻，造成意外视觉断层
