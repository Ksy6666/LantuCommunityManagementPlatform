# Critique Visual Hierarchy
审查屏幕的视觉层级——入口点、视线流、权重分布和强调。

## 审查维度

### 入口点（Entry Point）
最先捕获眼睛的元素。评估它是否是屏幕上*最重要*的元素。
- 是否有单一的支配元素，还是注意力分散？
- 大小、对比度或位置是否清晰地建立了入口点？
- 入口点是否与这个屏幕的主要用户目标匹配？

### 视线流（Eye Flow）
用户眼睛落地后的行进路径。评估路径是否经过精心设计且高效。
- 布局是否遵循 F 模式、Z 模式或有意的阅读顺序？
- 是否存在死胡同、循环或令人困惑的跳跃？
- 流动是否自然引导到主要行动号召？

### 权重（Weight）
各元素的相对视觉重要性。评估权重是否有目的地分布。
- 层级之间的大小差异是否至少 1.5 倍？
- 粗体/重体是否用得克制以保持信号价值？
- 背景填充、描边粗细和图标是否强化还是削弱了层级？

### 强调（Emphasis）
需要额外注意的特定元素。评估强调是否值得且唯一。
- 每个视图是否只有一个主要强调区域？
- 颜色、对比度或动效是否被用于强调——还是过度使用而相互抵消？
- 最高强调元素是否与利益相关者和用户优先级匹配？

## 输出格式
对每个维度，提供：
1. **Observation** — 你看到的（中立、事实）
2. **Problem** — 什么问题以及为何重要
3. **Fix** — 具体的、可操作的修改

评级：`pass` / `minor issue` / `major issue`
